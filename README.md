# Claude Session Restore has moved

This project continues as **Claude Switchboard**:

**https://github.com/akv2011/claude-switchboard**

Claude Switchboard does everything Claude Session Restore did (bring every Claude Code chat back in VS Code after a shutdown) and much more: one window for every chat with what each is doing, replies and model or effort changes per chat, account usage, full-text search, and sharing the work with a second machine over ssh and tmux, with a setup guide for that machine.

This repository is archived and will not be updated. Please use, star and open issues on Claude Switchboard instead.
